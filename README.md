# Descriptive Statistics Laboratory

An educational application developed with Python and Streamlit to explore and analyze datasets using descriptive statistics tools.

## Features

- Uploading and analyzing datasets.
- Calculating measures of central tendency.
- Calculating measures of dispersion.
- Analyzing quartiles and the interquartile range.
- Visualizing data through graphical representations.
- Exploring datasets from CSV files.

## Technologies

- Python
- Streamlit
- NumPy
- Pandas
- Matplotlib

## Educational Objective

To facilitate the understanding of fundamental descriptive statistics concepts through data analysis and the visualization of results.

## Local Installation and Execution

Install the dependencies:


pip install -r requirements.txt

Run the application:

streamlit run app_statistics.py
